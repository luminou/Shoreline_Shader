Hand-drawn waves, computedDes vagues dessinées, calculées

Six months in the R&D team of OLM Digital, the Japanese animation studio known for the Pokémon films, developing a procedural Maya shader that recreates hand-drawn anime water in 3D.Six mois au sein de l'équipe R&D d'OLM Digital, studio d'animation japonais connu pour les films Pokémon, à développer un shader procédural pour Maya qui reproduit en 3D l'eau dessinée à la main de l'animation japonaise.

The starting pointLe point de départ

In anime, every wave is drawn by handEn animation, chaque vague est dessinée à la main

In anime, the foam of a wave reaching the shore is drawn by hand, frame by frame, at 24 frames for every second of animation.Dans un anime, l'écume d'une vague qui arrive sur la plage est dessinée à la main, image par image, à raison de 24 images pour chaque seconde d'animation.

It looks great, but it is very slow. The goal: a tool that generates these waves automatically while keeping their hand-drawn look.C'est beau, mais très long. L'objectif : un outil qui génère ces vagues automatiquement tout en conservant leur aspect dessiné.

The sea of The End of Evangelion was a second reference.La référence principale était le film Pokémon 2 : Le pouvoir est en toi (Lugia, sorti au Japon en 1999), produit par OLM. The formulaLa formule

A wave described by a curveUne vague décrite par une courbe

No simulation: the position of each wave is computed from the animation time, so any frame can be rendered directly, with a consistent result.Aucune simulation : la position de chaque vague est calculée à partir du temps de l'animation. Chaque image peut être rendue directement, avec un résultat toujours identique.

U(t)=1.5−1.4×[1 − (1 − min(t, 0.6)0.6)2]+Recede Amount×S(max(0, t − Recede Start1 − Recede Start))

with t = fraction of the cycle = frac(time / Wave Cycle Duration + Phase Offset)

U(t)=1.5−1.4×[1 − (1 − min(t, 0.6)0.6)2]+R×S(max(0, t − tᵣ1 − tᵣ))

avec t = fraction du cycle = partie décimale de (temps / durée du cycle + décalage de la vague)

A bit of codeUn peu de code

The same formula, in MELLa même formule, en MEL

The beginning of the real script for wave A, written in MEL, Maya's scripting language. It runs on every frame of the animation.Le début du vrai script de la vague A, écrit en MEL, le langage de script de Maya. Il s'exécute à chaque image de l'animation.

// Where is the wave in its cycle? (1)
float $T = Ocean_Controls.waveCycleDuration;
float $timeShiftedA = time + $T * Ocean_Controls.phaseOffsetA;
float $rawCycleA = $timeShiftedA / $T;
float $t = $rawCycleA - floor($rawCycleA);

// It advances and slows down (2)
float $moveT = $t;
if ($moveT > 0.6) $moveT = 0.6;
$moveT = $moveT / 0.6;
float $pos = 1 - pow(1 - $moveT, 2);
float $posMapped = 1.5 - $pos * 1.4;

// Then it recedes, smoothly (3)
if ($t > $recedeStart) {
    $recede = ($t - $recedeStart) / (1.0 - $recedeStart);
    $recede = $recede * $recede * (3.0 - 2.0 * $recede);
    $posMapped += $recede * $recedeMag;
}

// Move the foam line mask (4)
Surf_line_mask_A.ramp[1].ramp_Position = $posMapped;
// Où en est la vague dans son cycle ? (1)
float $T = Ocean_Controls.waveCycleDuration;
float $timeShiftedA = time + $T * Ocean_Controls.phaseOffsetA;
float $rawCycleA = $timeShiftedA / $T;
float $t = $rawCycleA - floor($rawCycleA);

// Elle avance et ralentit (2)
float $moveT = $t;
if ($moveT > 0.6) $moveT = 0.6;
$moveT = $moveT / 0.6;
float $pos = 1 - pow(1 - $moveT, 2);
float $posMapped = 1.5 - $pos * 1.4;

// Puis elle recule, en douceur (3)
if ($t > $recedeStart) {
    $recede = ($t - $recedeStart) / (1.0 - $recedeStart);
    $recede = $recede * $recede * (3.0 - 2.0 * $recede);
    $posMapped += $recede * $recedeMag;
}

// On déplace le masque de la ligne d'écume (4)
Surf_line_mask_A.ramp[1].ramp_Position = $posMapped;
  1. 1Time. time is the current time in the animation. $t, between 0 and 1, is derived from it, as in the formula.Le temps. time est le temps dans l'animation. On en tire $t, entre 0 et 1, comme dans la formule.
  2. 2Ease-out. The first highlighted line is the square from the formula: fast arrival, then deceleration.Le ralentissement. La première ligne surlignée correspond au carré de la formule : arrivée rapide, puis ralentissement.
  3. 3Receding. The second highlighted line is the smoothstep function S(u) = u²(3 − 2u).Le recul. La seconde ligne surlignée est la fonction smoothstep S(u) = u²(3 − 2u).
  4. 4The mask. The result moves a mask (a black and white gradient) that defines where the foam is painted. The full script is about 230 lines per wave.Le masque. Le résultat déplace un masque (un dégradé noir et blanc) qui définit où peindre l'écume. Le script complet fait environ 230 lignes par vague.
